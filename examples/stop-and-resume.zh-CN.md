# 示例：材料进入检验与解除「止」

本示例来自协议构建过程中的假设情境，仅用于说明原文的止后操作，不是实际运行或性能测试结果。

| 项目 | 示例内容 |
| --- | --- |
| 停止位置 | 乙是否授权甲代表自己？ |
| 停止原因 | 缺少能够确认授权关系的依据 |
| 停止时状态 | 尚未形成有关授权的结论 |
| 补入材料 | 一份真实的签到表（示例假设） |
| 可以支持的判断 | 在本示例假设下，乙曾经到场 |
| 仍未解决的判断 | 乙是否授权甲代表自己 |
| 对原停止位置的处理 | 仍须执行「止」 |

材料真实并不意味着它能够补足原来的判断缺口。签到表可以进入检验，但不能仅凭到场事实推定授权。真实实验仍须登记提供者、来源、选择理由、补入时间和补入前运算状态或结论版本，且不得默认补入材料为真或完备。
