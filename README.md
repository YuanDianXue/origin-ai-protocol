## English overview (informative)

Origin Theory AI Protocol, Prototype 0.1, is a natural-language reasoning protocol that uses a five-part mutually constraining operational structure. Its aim is to make premises, subjects, relationships, costs, boundaries and judgments open to examination and revision, rather than to replace real-world decision-makers.

The Simplified Chinese protocol is the reference text. This repository is a specification prototype, not a runnable engine or a validated AI architecture. Use the complete, version-pinned document for experiments; distinguish original text, derivative interpretations and third-party implementations. No performance or conformance claim is made.
